Teclado

{% set ids_disponibles = teclados_disponibles | map(attribute='id') | list %}

La fuente de entrada que tiene el Mac mientras Claude teclea (se cambia allí con Ctrl+Espacio): si no coinciden, los acentos y { } [ ] | \ ~ @ salen distintos. Si el Mac está en español de España, «Español - ISO». También se cambia junto a «Pegar texto» mientras usas el Mac. Con «Español - ISO», el Mac tiene que tener el teclado como ANSI (si el asistente de teclado pregunta); con ISO, < > salen como º ª. Si el Mac usa otra (la latinoamericana, por ejemplo), pídele a Claude que calibre el teclado: lo mide en un TextEdit vacío y lo comprueba con una consulta que ejecutas tú en tu programa de consultas.

Lo que tarda, como mucho, la imagen del Mac en enseñar una tecla. Tras pulsar, el puente espera a ver el cambio hasta este tiempo; si se queda corto, una lectura puede salir con una página de antes o acabar antes de tiempo. La bitácora avisa si se acerca.

Márcala si en el Mac la rueda va al revés (pasa con el «desplazamiento natural» de macOS). Vale para Claude y para cuando usas el Mac desde aquí.

Claude Code

Se aplica a la siguiente conversación nueva o retomada; la abierta sigue con el suyo hasta que la reabras. Va por su nombre exacto, nunca por un alias. Fable 5.2 necesita Claude Code 2.1.322 o posterior. «El de mi Claude Code» no le pasa ninguno: usa el que tengas configurado.

Claude Code usa sus herramientas en este equipo (leer y escribir archivos, órdenes de terminal) sin preguntarte cada vez: --dangerously-skip-permissions. Tampoco te pregunta antes de cada clic o tecla en el Mac: lo que lo frena es el control, que sólo tiene cuando se lo das aquí. Se aplica a la siguiente conversación nueva o retomada; la primera vez Claude Code te pide confirmarlo.
