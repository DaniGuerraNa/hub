{# Dónde se añade uno. La guía de primer arranque lo explica, pero desaparece en cuanto hay un proyecto y no vuelve: quien ya tiene tres y quiere el cuarto no encuentra ninguna pista, porque el botón que buscaría no existe **a propósito** —crear y aplicar escriben dentro del repo de otro proyecto, y eso lo hace un agente con el usuario mirando, no el hub—. Una línea, sin caja y sin icono: es un apuntador, no una acción. #}

Para añadir uno, abre Claude Code en la carpeta del hub y dile «crea un proyecto» o «anexa mi proyecto»; para darle una capacidad a uno que ya tienes, «aplica el kit X aquí». El hub calcula y propone; escribir en tu repo lo hace el agente, contigo delante. Están en FLUJOS.md.
